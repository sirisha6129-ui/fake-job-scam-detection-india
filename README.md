# Fake Job & Internship Scam Detection (India)

This is a **Python Flask project** that detects potential fake job and internship scams based on keywords in the job description.

---

## Features

- Detects scam keywords like `fake`, `scam`, `work from home`, `quick money`, `urgent hiring`, `pay first`, etc.
- Mobile-friendly web interface using **Flask**.
- Easy to extend with more keywords.
- Real-time scam detection via web browser.
